# resources

curated external things — tools, docs, articles, repos, courses. one categorized file until
its size starts hurting retrieval, at which point it splits by category.

## rules when saving a url

1. **read the original source before summarizing it.** a summary written from the url, the
   title, or your prior knowledge is a fabrication. if it could not be opened, record that
   and store no summary.
2. store the **canonical url** and the **date accessed**.
3. record: purpose, useful capabilities or ideas, limits, and the retrieval trigger — the
   future situation in which this should resurface.
4. preserve installation or invocation commands **only when the source documents them**.
   never reconstruct a command from memory.
5. a saved resource is **not endorsed or verified**. saving is bookmarking, not vouching.
6. reopen the original before quoting exactly, installing, purchasing, or any consequential
   use. entries go stale silently.

## entry shape

```markdown
### res-slug — name
- url: <canonical url>
- accessed: YYYY-MM-DD
- purpose: what it is for
- useful for: specific capabilities or ideas
- limits: what it does not do, cost, platform, license
- retrieval trigger: when to surface this again
- commands: only if documented at the source
- status: unverified | tried | in use | rejected (with reason)
```
