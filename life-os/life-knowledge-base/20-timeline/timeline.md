# timeline

the chronological spine. one line per significant event, newest first, each linking to the
event note that holds the detail.

## rules

- this file holds **one line per event**, not the event's content. the detail lives in
  `events/YYYY/evt-YYYYMMDD-NNN.md`.
- dates use the user's timezone. unknown precision is stated (`2024`, `date_precision: year`)
  and never rounded to a specific day.
- events are not edited to reflect later understanding. a new record supersedes the old one
  and both stay readable.
- significance test: would this event change an answer six months from now? if not, it can
  live in a log rather than the timeline.
