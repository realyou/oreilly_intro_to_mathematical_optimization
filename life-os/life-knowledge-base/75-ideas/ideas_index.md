# ideas index

things worth keeping that are not commitments. an idea sitting here costs nothing; an idea
prematurely promoted to a project costs attention.

| id | idea | status | captured | note |
| --- | --- | --- | --- | --- |

## status values

| status | meaning |
| --- | --- |
| `not_started` | captured, untouched |
| `exploring` | actively being thought about |
| `promoted` | became a project — the idea note stays, with a bidirectional link |
| `parked` | deliberately set aside, with a reason and a revisit trigger |
| `rejected` | decided against, with the reason recorded |

## rules

- promotion **preserves the idea note** and creates a two-way link: the idea gets
  `promoted_to: prj-x`, the project gets `origin_idea: idea-x`. the idea is not deleted or
  renamed into the project.
- rejected ideas keep their reason. it is the reason, not the idea, that stops you
  re-litigating it in six months.
- capture the user's original wording. an idea paraphrased into corporate language usually
  loses the part that made it interesting.
