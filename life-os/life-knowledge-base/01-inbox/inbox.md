# inbox

unprocessed capture. the cheap place to put something when normalizing it now would cost
more than it is worth.

## rules

- an item here is **not** retrievable context yet. never answer a question from the inbox
  alone without saying it is unprocessed.
- each item gets a date and the user's own wording.
- processing an item means: writing it into the authoritative note, then either deleting the
  inbox line or replacing it with a link to where it landed.
- the inbox is not a backlog to admire. if an item has sat unprocessed through two reviews,
  either process it or say out loud that it is being dropped.
